This artifact regenerates the paper's empirical claims from source. It is a
**code + data** release: reported result JSONs, figure scripts, and rendered outputs
are not shipped, since the paper itself presents those numbers and figures. All

## 3. The certificate in one paragraph

For a frozen router score and a pre-registered nested threshold lattice, the **Budgeted
floor-aware certificate (Model B′, Algorithm 1)** either returns a threshold with a
simultaneous **selective-risk** guarantee (`R_Q ≤ α`) and **coverage-floor** guarantee
(`C_Q ≥ β`) at confidence `1 − δ`, or returns an **honest refusal** with axis attribution.
The risk test is a weighted empirical-Bernstein upper bound that absorbs the
`K`-cell weight-estimation error; the floor test is weight-free. This artifact audits its
**validity** (it never certifies an unsafe world beyond `δ`), its **conservativeness**
(how much slack it needs to certify), and its behavior against five baselines plus a
floor-augmented **SCoRE** e-value baseline (arm 7).

## 4. Real data — read before running the real legs

The real legs use **SQuAD → NewsQA** (covariate shift) with two capability legs
(leg 1: Meta-Llama-3-8B-Instruct; leg 2: DeepSeek-V4-Flash). The model weights are
**external** (Hugging Face / ModelScope) and are **not** redistributed here. The
text-free frozen artifacts shipped here contain eval-set model scores and 0/1 losses,
which regenerate the post-hoc frontier maps zero-GPU (`REPRODUCE.md` Path A).
Rerunning the full `certify_real` pipeline requires regenerating the full JSONL
cache from the external model weights (or adding a scores-only loader for per-pool score
exports). Source corpora carry their own licenses (SQuAD: CC BY-SA 4.0; NewsQA:
Microsoft Research license). See `data/README_DATA.md` for exactly what is shipped and
the regeneration path.

## 5. Scope & honesty guards (binding, from the result-to-claim gate)

This artifact reproduces **what the paper claims and no more**. In particular:
- The real-workload audit is a **single-corpus SQuAD→NewsQA feasibility audit**; the
  certificate's real-data output is **pre-deployment honest refusal** (both legs sit far
  below the floor). It is **not** a positive deployment-success demonstration.
- Positive B′ certification (R066) is a **targeted synthetic existence proof** (K=4), not a
  claim that B′ certifies easily or generally.
- No "experiments establish the two-axis functional form" reading — Theorem 1 carries it;
  the experiments are consistency checks.
